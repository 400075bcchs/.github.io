transform Property

A CSS property that lets you rotate, scale, skew, or translate an HTML element.

translate(x, y)

Moves an HTML element along the horizontal (x) and vertical (y) axes.

rotate(deg)

Rotates an element clockwise (positive degrees) or counter-clockwise (negative degrees).

scale(x, y)

Increases or decreases the size of an HTML element.

skew(x-deg, y-deg)

Tilts or slants an HTML element along the x and y axes.

transform-origin

Changes the anchor point where a transformation occurs.

3D Transforms: rotateY()

Rotates an element around the vertical axis.

Combining Transforms

Multiple functions can be applies, separated by spaces, like transform: translateY(-10px) scale(1.05);.

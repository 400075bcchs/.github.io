How to Embed a YouTube Video Into Your Website

Step 1: Choose Your Video and Click Share

Head to YouTube. Find the video you would like to use, and look beside the Like and Dislike button. Click the Share button (arrow). A menu should pop up.

Step 2: Click on Embed and Copy the HTML Code

From the menu, click on the Embed button. A box will open, showing an HTML code starting with an <iframe> tag. Click Copy to save the code.

Step 3: Paste the Code Into Your HTML File

Paste the copied code from YouTube into your HTML layout where you'd like the video to appear.
